# 对战场景

战斗学院、古代埃及、摩天大楼使用置中的建筑与地面背景。三张 `court-v3` 素材分别采用银蓝学院场馆、金砂青金石神庙、蓝灰铜饰都市屋顶，中央留出清晰的对局空间。双方墓地、除外区和阶段／轮次设施统一为低矮圆盘，分别适配学院的浅色材质、埃及的砂岩和都市的深色金属。场上隐藏伙伴。

墓地和除外区使用同样的圆形井盘，以蓝色和紫色柔光区分，不显示数量数字。圆盘采用单道细光环和柔和接触阴影，悬停、按压及卡堆变化只产生亮度反馈。阶段／轮次圆盘直接显示阶段名称和 `TURN` 数字；有原生计时器的对局使用同样的圆形计时盘。所有装饰固定在圆盘表面，中央文字区保持清晰。

摩天大楼的设施参考经典场地的嵌套圆形结构，采用分层深色钢制底座、细黄铜倒角、凹井内衬、沉头螺钉和装饰艺术镶条。阶段与计时表盘采用明亮的黄铜倒角、48 道分级刻度、双细饰环、四颗槽头螺钉及楼群尖顶装饰。中央复用原生场地已加载的抗锯齿字体，并随真实表盘平面固定：阶段名称居中放大，回合信息置于上方，配合金色渐变、细分隔线和菱形饰纹；字体材质独立管理，保留无字体时的几何文字回退。双方墓地／除外区使用一致尺寸，按屋顶中轴旋转对称排列；阶段与计时盘分别留在两侧设施列内，所有设施完整位于加宽的金色战斗边框内。

摩天大楼墓地／除外盘的外壳和井口使用 160 段圆环，加入加宽的黄铜倒角、车削井口、八颗露出的槽头螺钉和四组阶梯式镶条。深色金属内壁连接井底，井底低于井口约 .336 单位；蓝紫色光收窄至 .045 单位的井口嵌线，并降低井内反射亮度。占地仍为 4.5×4.5，原生所属方、墓地／除外列表及点击身份保持一致。

战斗学院和古代埃及采用相同的 160 段精细圆环、48 道分级刻度和深凹井盘标准。学院使用象牙白盘面、拉丝银边、深蓝刻度、十字螺钉、书页盾徽及月桂；埃及使用砂岩阶梯底座、青金石盘面、暖金刻度、翼日、莲花浮雕、石侧凹槽和青金石嵌章。学院井深 .338 单位，埃及 .336 单位，蓝／紫光圈分别收窄至 .044／.045 单位。三主题共用原生抗锯齿字体；学院为象牙盘面上的深蓝文字，埃及与都市为深色盘面上的金色文字。两场地各自按背景边界校正设施坐标，双方井盘等大且旋转对称，避开原生场地魔法及卡组区域。

卡位角标直接使用原生卡片坐标，涵盖双方各十个区域及两个额外怪兽区。场上卡片和设施有柔和接触阴影。设施按各主题的 `fixture-layout-v3.json` 和当前相机投影适配，点击区域跟随模型轮廓，并通过薄碰撞体避开隐藏原生场地的射线遮挡。保留原生点击身份、堆叠动画和退出后的碰撞体恢复。

阶段选择参考经典场地的横排圆盘，三主题统一使用 740 单位宽的底板和一行四枚 136 单位圆形按钮。圆内直接复用原生“卡片 1／交叉双剑／卡片 2／退出箭头”图标，圆下居中显示本地化阶段名称；标题简化为“选择阶段”，不再显示当前阶段提示、阶段序号或“可前往／不可前往”状态文案。当前项以强化边圈和顶部指针标记，可用项与禁用项通过填色、边圈和图标明暗区分。学院使用银蓝刻度及盾翼冠饰，埃及使用金色刻度、青金石嵌线及神庙门楣，都市使用钢制边圈、黄铜刻度及城市冠饰。圆形按钮保持原生对象、阶段响应、当前项关闭操作和禁用状态；圆盘外的透明区域不触发点击。取消操作留在独立底栏。阶段底板不透明度为 .99，按钮为 1。普通规则弹窗保留原有布局，学院阅读底板不透明度为 .97，埃及和都市为 .96。原生阶段响应、禁用状态和键盘导航保留。选位置提示和普通通知仍使用半透明底板，学院为 .80，埃及和都市为 .74；短暂的阶段横幅为 .42。选卡框保留完整卡面，将卡背卷角、等级及灵摆等状态信息移到卡面下方。

玩家与对手的头像、名字、血量分别布局。默认头像显示所选人物，AI 使用其分身人物设置，静音时仍显示人物头像。原生规则、点击回调与资源失败回退保留。
