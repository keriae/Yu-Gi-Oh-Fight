# 对战场景

战争学院、古代埃及、摩天大楼使用置中的建筑与地面背景。三张 `court-v3` 素材分别采用银蓝学院场馆、金砂青金石神庙、蓝灰铜饰都市屋顶，中央留出清晰的对局空间。双方墓地、除外区和阶段／轮次设施统一为低矮圆盘，分别适配学院的浅色材质、埃及的砂岩和都市的深色金属。场上隐藏伙伴。

墓地和除外区使用同样的圆形浅井，以蓝色和紫色柔光区分，不显示数量数字。圆盘采用单道细光环和柔和接触阴影，悬停、按压及卡堆变化只产生亮度反馈。阶段／轮次圆盘直接显示阶段名称和 `TURN` 数字；有原生计时器的对局使用同样的圆形计时盘。模型取消机械浮雕、夹片、旋转饰圈、方形铭牌框和阶段灯阵。

卡位角标直接使用原生卡片坐标，涵盖双方各十个区域及两个额外怪兽区。场上卡片和设施有柔和接触阴影。设施按各主题的 `fixture-layout-v3.json` 和当前相机投影适配，点击区域跟随模型轮廓，并通过薄碰撞体避开隐藏原生场地的射线遮挡。保留原生点击身份、堆叠动画和退出后的碰撞体恢复。

阶段选择使用 2×2 按钮，只显示阶段名称，以颜色区分当前、可用和禁用状态。阶段选择与原生规则弹窗使用接近不透明的阅读底板，学院底板的不透明度为 .97，埃及和都市为 .96，避免场地文字和效果透入阅读区。当前阶段按钮的不透明度为 .98，可用按钮为 .94（主要操作为 .98），禁用按钮为 .65。选位置提示和普通通知仍使用半透明底板，学院不透明度为 .80，埃及和都市为 .74；短暂的阶段横幅为 .42。选卡框保留完整卡面，将卡背卷角、等级及灵摆等状态信息移到卡面下方。

玩家与对手的头像、名字、血量分别布局。默认头像显示所选人物，AI 使用其分身人物设置，静音时仍显示人物头像。原生规则、点击回调与资源失败回退保留。

运行素材位于 [content/client-ui/duel-scenes](../../content/client-ui/duel-scenes)，文件哈希、提示词与实现来源见 [素材清单](duel-scene-assets.json)。清单只记录当前实际存在的运行素材和使用中的实现来源。场地图片由 AI 生成，保留提示词和素材来源以便维护。
